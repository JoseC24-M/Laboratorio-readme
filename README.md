## Descripción

**Biblioteca** es una plataforma orientada al manejo integral de bibliotecas digitales e institucionales. Permite a los usuarios explorar catálogos por categorías, solicitar préstamos temporales de libros y recibir alertas sobre fechas de devolución, ofreciendo una interfaz rápida e intuitiva.
